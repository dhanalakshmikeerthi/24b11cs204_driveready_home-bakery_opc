# Day 2 – Messages, Prompts, JSON and Python

## Overview

Today we learned how AI applications communicate with language models and how Python can be used to structure, manage, and control AI-related tasks.

## What We Learned

### Messages and Roles

We learned about different message roles used when communicating with AI models and how each role has a specific purpose.

### System Prompt

We learned that a system prompt provides instructions that guide the behavior, purpose, and response style of the AI model.

### Few-Shot Examples

We learned how few-shot examples can guide an AI model by showing the expected pattern of input and output.

### Asking for JSON

We learned how to request structured responses in JSON format.

JSON makes AI responses easier for programs to read, process, and use.

### Memory by Hand

We learned the basic idea of maintaining memory manually by storing useful information and providing it to the model when required.

### Dictionaries and JSON in Python

We learned how Python dictionaries can store structured key-value data and how JSON is commonly used for exchanging structured data.

### Functions and Type Hints

We learned how functions can be defined using type hints to make expected inputs and outputs clearer.

### Decorators

We learned that decorators can add additional behavior to functions without changing their original implementation.

### try / except

We learned how try/except is used to handle errors safely in Python and prevent programs from stopping unexpectedly.

## Key Takeaways

- Messages and roles help structure communication with AI models.
- System prompts guide model behavior.
- Few-shot examples help guide the expected response pattern.
- JSON provides structured AI output.
- Manual memory helps maintain useful information.
- Python dictionaries store structured data.
- Type hints improve code clarity.
- Decorators extend function behavior.
- try/except provides error handling.

## Conclusion

Day 2 helped us understand the connection between AI prompting and Python programming. We learned how to structure AI interactions, manage information, work with structured data, and handle errors while developing AI-related applications.
