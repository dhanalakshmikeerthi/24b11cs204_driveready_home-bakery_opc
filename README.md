# Understanding AI Context, Learning, Hallucination and RAG

## Overview

This learning activity helped us understand how AI language models process information, how they learn, why they sometimes give incorrect answers confidently, and how providing relevant information can improve their responses.

## What We Learned

### 1. Context Window

A context window is the amount of information an AI model can handle in a single call.

It includes:

- System instructions
- Previous conversation or history
- User's question
- Documents or other information provided
- The answer generated by the model

All of this information must fit within the model's context window.

### 2. Self-Supervised Learning

AI language models can learn through self-supervised learning.

The model learns patterns from large amounts of existing text by predicting missing or next parts of the text.

This helps the model learn:

- Language structure
- Grammar
- Word relationships
- Common patterns
- Knowledge present in the training data

The important point is that the training data itself provides the learning signal, so separate human labels are not required for every training example.

### 3. Hallucination

Hallucination is when an AI model produces information that sounds correct or confident but is actually incorrect or unsupported.

We learned that AI models are designed to generate likely and meaningful text. They do not automatically verify whether every generated statement is true.

Therefore, when the model does not have reliable information about something, it can sometimes produce an incorrect answer.

### 4. Importance of Context

Providing relevant information to the AI at the time of asking a question can help the model give a more accurate and grounded response.

The model can use the provided information instead of depending only on patterns learned during training.

### 5. Retrieval-Augmented Generation (RAG)

RAG stands for **Retrieval-Augmented Generation**.

RAG combines information retrieval with AI text generation.

It retrieves relevant information and provides it to the AI model as context before generating the answer.

RAG helps:

- Provide relevant information
- Ground responses in available data
- Reduce hallucinations
- Improve the usefulness and reliability of AI responses

RAG does **not** retrain the AI model. It provides additional information to the model when the question is being answered.

## Key Takeaways

- AI models have a limited context window.
- The context window contains the information needed for a single interaction.
- Self-supervised learning allows models to learn from large amounts of text.
- AI generates plausible language but does not automatically guarantee that every statement is true.
- Hallucination can occur when the model generates unsupported or incorrect information.
- Providing relevant context

# Day 2 Tutorial – Messages, Prompts, JSON and Python

## 📌 Today's Learning

Today we learned how AI applications communicate with language models and how Python can be used to structure, manage, and control AI-related tasks.

### 1. Messages and Roles

We learned that conversations with an AI model can contain different types of messages and roles. Each role has a specific purpose in controlling how the model receives and responds to information.

### 2. System Prompt

We learned about the **system prompt**, which provides instructions that guide the behavior, purpose, and response style of the AI model.

### 3. Few-Shot Examples

We learned how **few-shot examples** can guide an AI model by providing examples of the expected input and output format.

This helps the model understand the required pattern without changing or retraining the model.

### 4. Asking for JSON

We learned how to request responses in **JSON format**.

Using structured JSON makes AI responses easier for programs to read, process, and use.

### 5. Memory by Hand

We learned the basic idea of maintaining memory manually by storing useful information and providing it to the model when needed.

This helps maintain relevant information across interactions.

### 6. Dictionaries and JSON in Python

We learned the relationship between **Python dictionaries and JSON**.

Python dictionaries can store structured key-value data, while JSON is a commonly used format for exchanging structured data between applications.

### 7. Functions and Type Hints

We learned how Python functions can be defined with **type hints**.

Type hints make the expected input and output types clearer and improve code readability and maintainability.

### 8. Decorators

We learned about **decorators** in Python.

Decorators allow additional behavior to be added to functions without changing the original function's main code.

### 9. try / except

We learned how **try/except** is used for error handling in Python.

It allows programs to handle errors safely instead of stopping unexpectedly.
